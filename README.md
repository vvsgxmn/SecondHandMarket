# 基于SpringBoot+Vue的二手市场交易系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

SecondHandMarket 是一款面向校园场景的二手闲置交易平台，支持商品发布、分类浏览、求购对接、线下面交下单、订单跟踪、退款维权与交易评价，普通用户与管理员双端协同，适合毕设、课设与学习参考。

## 主要功能模块

- **用户认证模块**：支持普通用户与管理员登录注册，按角色跳转用户端/管理端
- **商品交易模块**：闲置发布、分类筛选、关键词搜索、详情留言与收藏
- **线下面交模块**：约定交易地点下单、买卖订单管理与交易完成确认
- **退款维权模块**：买家申请退款举证、卖家审核与平台仲裁
- **求购广场模块**：发布求购需求、浏览他人求购信息
- **后台运营模块**：数据看板、商品监管、订单查阅、用户管理与分类维护

## 技术架构

- **后端**：Spring Boot 2.6.13 + MyBatis-Plus 3.5.3 + Lombok
- **前端**：Vue 3 + TypeScript + Vue Router + Pinia + Element Plus + Vite 5
- **数据库**：MySQL 8.0
